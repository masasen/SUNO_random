# SUNO_random

SUNO Simple Prompt Builder V4 の GitHub Pages 公開用リポジトリです。

- `index.html` は元ファイル `suno_simple_prompt_builder_v4.html` の内容をそのまま複製しています。
- ブラウザ内でプロンプトをランダム生成します。サーバーや外部 API は不要です。
- 編集内容、履歴、プリセットは利用中の端末とブラウザの `localStorage` に保存され、端末間では同期されません。
- 「SUNO AI を開く」の自動入力には、元HTMLの説明どおり別途 Tampermonkey スクリプトが必要です。

公開設定: GitHub Pages → Deploy from a branch → `main` / `(root)`。
